# Notification Center — EXPERIMENTAL (reversible) · V2

نظام إشعارات داخلي بين المدير والمندوب. **ميزة تجريبية**، مصمّمة لتُحذف بالكامل دون أي
أثر على بقية النظام.

## ماذا تفعل (V2)

- **المدير** (لوحة التحكم → زر "الإشعارات"):
  - إنشاء إشعار: نوع، عنوان، نص، **المرسل إليه من قائمة الأجهزة** (لا كتابة يدوية)،
    عميل اختياري، منتج اختياري.
  - **كشف حساب** يرفع **مرفقاً واحداً** (PDF / PNG / JPG / JPEG، حتى 20MB).
  - **تعديل** (قبل القراءة فقط)، **حذف** (قبل القراءة)، **إلغاء** (بعد القراءة).
  - لوحة تعرض لكل إشعار: النوع، المرسل إليه، الحالة، الإنشاء، القراءة (بواسطة + وقت)،
    التنفيذ (بواسطة + وقت)، والإجراءات.
  - **صفحة سجل** مع فلاتر (الكل/جديد/تمت القراءة/تم التنفيذ/ملغى) وبحث بالعنوان/المندوب/التاريخ/النوع.
- **المندوب** (أيقونة الجرس في ترويسة الكتالوج):
  - يسجّل **اسم جهازه مرة واحدة** (من إعدادات الجرس) — يُخزّن محلياً ويُسجَّل في الخادم.
  - نافذة جانبية: أيقونة، عنوان، وصف قصير، وقت، شارة حالة، وعدّاد غير المقروء.
  - الفتح: منتج/عرض → صفحة المنتج، كشف حساب → عارض المرفق (PDF/صورة داخل التطبيق)،
    رسالة/إعلان → قارئ داخلي. الإعلان **للقراءة فقط**؛ البقية تُنفَّذ بزر "تم التنفيذ".
- **الحالات**: جديد / تمت القراءة / تم التنفيذ / ملغى (شارات ملوّنة).
- **الإلغاء**: يختفي فوراً عند المندوبين الذين لم يفتحوه، ويبقى "ملغى" لمن فتحه.
- **التحديث**: Polling كل 30 ثانية (بدون WebSocket).
- كل الحوارات تستخدم حوار التطبيق (لا `confirm()` من المتصفح).

## قاعدة البيانات

- جدول `notifications` (يُوسَّع تلقائياً بأعمدة V2 عبر ALTER TABLE عند أول تشغيل).
- جدول جديد `notification_devices` (سجل الأجهزة).
- المرفقات تُخزَّن في `uploads/attachments/` وتُقدَّم على `/uploads/attachments/`.
- لا يُعدَّل أي جدول آخر.

## الأمان

إجراءات المدير (إنشاء/تعديل/إلغاء/حذف) محميّة على الواجهة بنفس PIN الذي يحمي لوحة
المدير (لا يوجد Auth على الخادم في هذا التطبيق — الـ PIN بوابة على الجهاز). الخادم
يفرض قواعد الحالة الفعلية: التعديل/الحذف مسموح فقط والحالة "جديد".

## كيفية الحذف الكامل (Rollback)

1. احذف مجلد الواجهة: `src/features/notifications/`
2. احذف جسور المسارات: `src/routes/notifications.tsx` و`src/routes/notifications-history.tsx`
   (وأعد توليد `routeTree.gen.ts` بتشغيل `npm run dev`/`npm run build`).
3. احذف مجلد الخادم: `server/src/notifications/`
4. أزل الأسطر المعلَّمة `[notifications-feature]` في:
   - `server/src/app.ts` (سطرا import + register)
   - `src/routes/admin.tsx` (زر "الإشعارات")
   - `src/routes/catalog.tsx` (أيقونة الجرس `<NotificationBell />`)
   - `src/routes/product.$id.tsx` (شريط المصدر + قراءة `search.notif`)
   - `vite.config.ts` (`/notifications-api` في قائمة الـ proxy)
   - `public/sw.js` (`notifications-api` في `isApiRequest`)
5. (اختياري) أسقط الجدولين: `DROP TABLE notifications; DROP TABLE notification_devices;`
   واحذف مجلد `server/uploads/attachments/`.
